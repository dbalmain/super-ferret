# Ferret

## Mission Statement

Linux has the best desktop search experience of any operating system.

## Features

- Standard search features of all files on the operating system.
- Much faster find alternative
- In-file search with plugins for non-text datatypes and out-of-the-box handling
  for:
  - PDFs
  - image metadata
  - video metadata
- Regex search for code
- metadata search with 100% coverage of find's features
- Nice to CPU
- Minimal index
- Fast enough performance (CPU indexing impact and index size take priority over
  performance)
- TUI
- Tauri UI
